Excel Data Labeller

Chunked editing for large Excel files

The Problem

  • Large Excel files
  • Many editors working simultaneously
  • Merge conflicts and coordination overhead

Solution

Upload → chunk by rows → claim chunks → edit row-by-row → export merged

Architecture

  • Backend: Node.js, Express, SQLite, ExcelJS, multer
  • Frontend: React, Vite, React Router

Key Features

  • Upload or preload Excel files
  • Sheet and column configuration
  • Chunking widget
  • Claim / resume chunks
  • Tags per chunk

Re-chunk

  • Hierarchical chunks
  • Drill down: container → children
  • Re-chunk leaf chunks

Export

  • Merge all edits
  • Pre-export integrity check
  • Download result

Run It

npm run setup && npm run start

http://localhost:36001
